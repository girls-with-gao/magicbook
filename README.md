# 매직북

아이의 그림 또는 그림일기를 AI가 짧은 동화와 쉬운 영어 이야기로 확장해주는 해커톤 MVP입니다.

## 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## OpenAI 연동

`.env.example`을 참고해 `.env`에 `OPENAI_API_KEY`를 설정하면 실제 이미지 분석과 이야기 생성이 동작합니다.

API 키가 없을 때는 발표와 UI 점검을 위한 데모 이야기를 생성합니다.

## MVP 범위

- 그림/그림일기 업로드
- 아이 이름, 나이, 테마 입력
- 완성형/이어쓰기형 선택
- 4~6페이지 동화 생성
- 쉬운 영어 버전 보기
- 다음 상상을 돕는 질문
- PDF 저장
