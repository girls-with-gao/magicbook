# 친구 이야기 이어 쓰기 · 결말 카드 · 함께 지은이 계획

작성일: 2026-09-19
기준 브랜치: `design/unify-look`

## 목표

"내가 남의 이야기를 완성했다"는 뿌듯함을 주되, 아이들끼리 실제 데이터를 주고받지 않는다.
아이가 가장 어려워하는 결말 짓기를 카드로 돕는다.

원칙은 그대로 지킨다.
- 서버나 DB에 아이 그림·이야기를 저장하지 않는다. 책은 브라우저에만 보관한다.
- 점수·순위·경쟁을 넣지 않는다. "우승작" 대신 "함께 지은 책"으로 표현한다.
- 친구 이야기는 팀이 미리 만든 예시이며, 화면에 그렇게 밝힌다.

## 1. 결말 카드 (작업량: 작음)

마지막 편(4편)의 갈림길을 "다음에 뭐 할까?"가 아니라 **"어떻게 끝낼까?"**로 바꾼다.

- `lib/ai-prompts.ts`의 `buildOpeningPrompt`에 마지막 편 분기를 추가한다.
  - 질문은 결말을 묻는 한 문장으로 (예: "이야기를 어떻게 끝낼까?").
  - 카드 3장은 모두 이야기를 닫는 행동으로 (예: 🏠 집으로 돌아가기 / 🎁 친구에게 선물하기 / 🌙 다 같이 잠들기).
- `lib/demo-data.ts`의 4편 갈림길을 결말형으로 바꾼다.
- 테스트: 4편 opening 프롬프트에 결말 지시가 있고, 1~3편에는 없다.

## 2. 친구 이야기 이어 쓰기 (작업량: 중간)

### 데이터
`lib/seed-books.ts`에 미완성 예시 이야기 3편을 넣는다. 각 항목:

```ts
type SeedBook = {
  id: string;
  authorName: string;        // 예: "민준"
  authorAge: number;
  title: string;
  hook: string;              // 카드에 보여줄 한 줄
  imagePaths: string[];      // /seed-1-1.svg 처럼 public 파일
  chapters: { analysis: DrawingAnalysis; story: BilingualStory }[]; // 1~2편
};
```

- 그림은 `public/`에 SVG로 새로 만든다 (편당 1장, 총 4~5장).
- 주제는 지금 예제(바다)와 겹치지 않게 한다: 우주 토끼 / 공룡 도서관 / 눈사람 마을 등.

### 화면
1. 첫 화면 아래에 입구 카드: **"친구가 쓰다 만 이야기, 내가 완성해볼까?"**
2. 새 단계 `friends`: 예시 이야기 3장을 카드로 보여준다. 각 카드에 표지 그림, 지은이, 한 줄 소개, "○편까지 썼어요" 표시. 상단에 "예시로 준비한 이야기예요" 안내.
3. 카드를 고르면 그 이야기를 읽는다(기존 책 보기 화면 재사용, 읽기 전용).
4. **"내가 이어 그릴래 →"**를 누르면
   - 예시 편들을 내 책의 앞 편으로 복사하고(그림은 SVG→PNG로 변환해 보관),
   - 책에 `origin: { type: "friend", seedId, authorName }`을 기록하고,
   - 업로드 단계로 이동한다. 이후 흐름은 지금 이어 그리기와 동일하다.

### 데이터 구조 변경 (`lib/story-types.ts`)
```ts
type StoryChapter = { ...기존, author?: string };   // 친구 편에는 친구 이름
type StoryBook   = { ...기존, origin?: { type: "friend"; seedId: string; authorName: string } };
```

### 파일
- 신규: `lib/seed-books.ts`, `components/friend-picker.tsx`, `public/seed-*.svg`
- 수정: `lib/wizard.ts`(단계 `friends` 추가), `components/story-studio.tsx`, `lib/book-storage.ts`(origin 유지), `app/globals.css`

## 3. 함께 지은이 (작업량: 작음)

- 책 표지: `지은이 · 민준 + 수민` (친구 이야기에서 시작한 책만)
- 각 편 페이지 배지: `1편 · 민준이 씀`, `3편 · 수민이 씀`
- 부모 요약에 "함께 지은 친구" 줄 추가
- 완성 화면 문구: "민준이의 이야기를 수민이가 완성했어요!"
- 파일: `components/story-book.tsx`, `components/story-studio.tsx`

## 작업 순서

1. 결말 카드 (독립적, 바로 확인 가능)
2. 예시 이야기 데이터 + SVG 4~5장
3. `friends` 단계와 고르기 화면
4. 예시 편을 내 책으로 복사하는 흐름
5. 함께 지은이 표시
6. 테스트 · 데모 모드 전체 흐름 확인

## 위험과 대응

- **브라우저 저장 용량:** 친구 편 2장 + 내 편 2장이면 그림 4장이다. 지금처럼 긴 변 1280px JPEG로 줄이면 약 200KB로, 한도 안에 들어온다.
- **예시를 진짜 사용자 데이터로 오해:** 고르기 화면과 발표에서 "팀이 만든 예시"라고 분명히 밝힌다.
- **이야기 톤이 튐:** 친구 편 요약을 그대로 이어 쓰기 프롬프트에 넣어, 인물과 세계관을 유지한다(기존 방식과 동일).
- **범위 초과:** 3번(함께 지은이)까지는 표시 작업이라 안전하다. 실제 공유·업로드·검수는 이번 범위가 아니다.

## 완료 기준

- 데모 모드에서 친구 이야기를 골라 읽고, 내 그림을 올려 이어 쓰고, 완성된 책에 두 사람 이름이 나온다.
- 마지막 편 갈림길이 결말 카드로 나온다.
- 새로고침해도 이어 쓰던 친구 책이 남는다.
- `npm test`와 `npm run build` 통과.

## 이번 범위가 아닌 것 (발표에서 다음 단계로 설명)

- 실제 아이들 사이의 공개·공유, 신고·검수, 보호자 동의 흐름
- 순위·베스트셀러. 대신 어른이 고르는 "이달의 이야기책"으로 설명한다.
