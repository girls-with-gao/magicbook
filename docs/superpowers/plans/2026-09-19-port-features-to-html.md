# Next 버전 기능을 팀원 HTML 버전으로 옮기는 계획

작성일: 2026-09-19
기준: `public/index.html` + `public/app.js` + `server.js` (팀원 시제품)을 **최종 결과물**로 삼는다.
가져올 곳: `design/unify-look` 브랜치의 Next 앱 (`app/`, `components/`, `lib/`, `tests/`)

## 왜

팀원 버전의 **쪽마다 AI 삽화 + 아이 그림 주인공 합성**이 결과물로 가장 강하다.
Next 버전의 **아이 주도 흐름(단계·갈림길·음성)과 이어 그리기·동화책·친구 이야기**를 그 위에 얹는다.

## 구조 결정

순수 로직은 한 벌만 두고 브라우저와 서버가 같이 쓴다.

```
public/shared/   ← 브라우저와 server.js가 함께 import 하는 ESM 모듈 (테스트 대상)
  korean.js         조사 붙이기
  wizard.js         단계 전환 규칙
  story-normalize.js  AI 응답 정리 + 시작·끝 합치기
  book-storage.js   책 보관(브라우저 저장소 주입식)
  seed-books.js     친구 이야기 예시 데이터
  demo-data.js      API 키 없을 때 쓰는 예제
  ai-prompts.js     분석·시작·끝 프롬프트
server.js        ← 위 모듈을 import, HTTP API 제공
public/app.js    ← 위 모듈을 import, 화면 담당
tests/           ← vitest가 public/shared/*.js를 테스트
```

- 타입스크립트를 버리고 JSDoc 주석으로 대체한다. 빌드 단계를 두지 않는다.
- `public/shared`는 정적 파일로도 서빙되므로 브라우저에서 `import`로 바로 쓴다.
- `app.js`는 `<script type="module">`로 불러온다.

## 단계

각 단계가 끝날 때마다 `npm test`와 브라우저 확인을 하고 커밋한다.

### 1단계 · 공용 모듈 옮기기
- `lib/korean.ts`, `lib/wizard.ts`, `lib/story-normalize.ts`, `lib/book-storage.ts`, `lib/seed-books.ts`, `lib/demo-data.ts`, `lib/ai-prompts.ts`를 `public/shared/*.js`로 옮긴다(타입 제거, 동작 동일).
- `tests/`의 기존 테스트가 새 경로를 보도록 고친다. 테스트 개수는 줄지 않아야 한다(현재 67개).
- `public/seed-*.svg`, `public/sample-drawing*.svg`는 그대로 쓴다.

### 2단계 · 서버 API 정리
`server.js`에 다음 경로를 만든다. 기존 `/api/generate-story`는 4단계까지 남겨 두었다가 마지막에 지운다.

- `POST /api/analyze` — 그림·손글씨 읽기. Next `app/api/analyze/route.ts`와 같은 입력·출력. 키 없으면 `demoAnalysisFor(chapter)`.
- `POST /api/story` — `phase: "opening" | "ending"`. Next `app/api/story/route.ts`와 같음.
- `POST /api/page-art` — **팀원 코드 유지**. `server.js`의 `generatePageImage`를 한 쪽씩 만들도록 분리한다. 입력: 이야기 쪽 정보 + 아이 그림, 출력: 삽화 data URL.
- 키가 없을 때는 모든 경로가 예제 모드로 응답하고 `demoMode: true`를 함께 준다.

### 3단계 · 5단계 흐름 화면
`index.html`을 단계형으로 바꾼다. 팀원 첫 화면(히어로)은 1단계 위에 그대로 둔다.

1. 그림 올리기: 사진, 별명, 나이, 개인정보 확인, "예제로 시작하기", "친구 이야기" 입구
2. 부모 확인: AI가 읽은 등장인물·장소·사물·분위기·그림일기 글을 고칠 수 있게
3. 언어 고르기: 한국어 / English / 함께 — **여기에 팀원의 주제 칩 5개와 완성형·이어쓰기형도 함께 둔다**
4. 이야기 보기
5. 다시 그리기

- 현재 `app.js`의 입력 항목(주인공 이름·설명 등)은 2단계 부모 확인 화면으로 옮긴다. 아이가 타이핑할 일이 없어야 한다.
- 단계 전환은 `shared/wizard.js`를 쓴다.

### 4단계 · 이야기 화면 + 갈림길 + 음성
- 이야기 쪽 렌더링은 **팀원 방식 유지**: 생성된 배경 + `extractCharacter()`로 오려낸 주인공 + framing/textSide.
- 앞 2쪽을 보여준 뒤 **갈림길 화면**을 띄운다. Next `components/choice-picker.tsx`의 동작을 그대로 옮긴다.
  - 카드 3장(이모지 + 한국어 + 영어), 누르면 읽어주고 선택만 됨
  - "💡 내 생각이 있어요" + 🎤 음성 입력(Web Speech API) → 들은 말을 읽어주고 확인 → 부모 대신 적기
  - 확인 버튼을 눌러야 다음으로
- 선택을 `/api/story` `phase:"ending"`에 넘겨 뒤 2쪽을 만든다.
- 문장 읽어주기(`speechSynthesis`) 버튼을 쪽마다 둔다.
- **삽화 생성은 보고 있는 쪽만** 만든다(미리 4장 만들지 않는다). 만드는 동안에는 오려낸 주인공만 먼저 보여 준다.

### 5단계 · 이어 그리기 + 동화책
- `shared/book-storage.js`로 브라우저에 책을 보관한다(그림은 긴 변 1280px JPEG로 줄여 저장).
- 마지막 화면: "다음 장면 그림 올리기" / "지금까지 만든 책 보기" / "오늘은 여기까지"
- 책 보기: 표지(지은이), 쪽 넘기기, 단어 카드, 부모 요약, 인쇄·PDF. 팀원의 `window.print()`와 인쇄 CSS를 살린다.
- 마지막 편에서는 갈림길이 **결말 카드**로 나온다.

### 6단계 · 친구 이야기 이어 쓰기
- 첫 화면 입구 → 친구 이야기 3편 고르기 → 내 책으로 가져오기 → 이어 그리기
- 표지 "지은이 · 민준 + 수민", 편마다 "○편 · 민준이 씀", 부모 요약에 함께 지은 친구

### 7단계 · 정리
- `/api/generate-story`와 쓰지 않는 코드 삭제
- `app/`, `components/`, `lib/`, `next.config`, Next 의존성 제거 (팀원 버전으로 일원화한 뒤)
- `README.md`, `AGENTS.md`, 실행 방법 갱신
- **배포 방법 재확인**: 지금 `server.js`는 순수 Node 서버라 Vercel 설정이 Next 때와 다르다. `VERCEL_DEPLOY_2026-09-16.md`를 고쳐야 한다.

## 지키면서 옮길 것

- 아이가 타이핑하지 않는다. 고르기·말하기·그리기로만 진행한다.
- 아이 그림이 주인공이다. AI는 배경만 그리고 주인공은 원본에서 오려 쓴다.
- 서버에 아이 그림·이야기를 저장하지 않는다. 책은 브라우저에만 둔다.
- 점수·순위·무한 추천을 넣지 않는다.
- 친구 이야기는 팀이 만든 예시라고 화면에 밝힌다.
- API 키가 없어도 예제 모드로 5단계가 끝까지 돌아간다.

## 위험

- **대기 시간**: 한 편에 AI 호출이 분석 1 + 이야기 2 + 삽화(보는 쪽마다) 1~4회다. 쪽마다 만들면 시연이 늘어진다. 보고 있는 쪽만 만들고, 다음 쪽은 미리 한 장만 앞서 만든다.
- **오려내기 품질**: 지금 `extractCharacter()`는 흰 종이만 지운다. 색지·그림자·격자무늬가 남는 사례가 있으니 기준값을 조정하고, 실패하면 원본을 그대로 쓴다.
- **삽화에 글자**: 생성 이미지에 읽을 수 없는 글자가 들어가는 일이 있다. 프롬프트의 금지 문구를 유지한다.
- **브라우저 저장 용량**: 삽화까지 저장하면 5MB를 넘는다. 책에는 **아이 원본 그림만** 저장하고 삽화는 저장하지 않는다.
- **테스트 축소**: 타입스크립트를 버리면서 테스트가 깨지기 쉽다. 단계마다 `npm test`가 통과해야 다음으로 간다.

## 완료 기준

- API 키 없이: 친구 이야기 고르기 → 이어 그리기 → 갈림길(카드/음성) → 4편 → 동화책 → 인쇄까지 진행된다.
- API 키 있음: 손글씨를 읽고, 쪽마다 삽화가 뜨고, 아이 선택이 뒷이야기에 반영된다.
- 휴대폰 폭에서 5단계가 모두 정상으로 보인다.
- `npm test` 통과(67개 이상), 새 구조에 맞는 테스트 추가.
